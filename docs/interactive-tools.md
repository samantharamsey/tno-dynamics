## Sun–Neptune zero-velocity surfaces

The zero-velocity surface explorer shows how the energetically accessible regions of the circular restricted three-body problem change with the Jacobi constant. Two linked views show the full Sun–Neptune system and the local structure near Neptune.

- Drag the Jacobi-constant slider for immediate updates.
- Rotate and zoom both three-dimensional views independently.
- Compare critical values associated with the collinear Lagrange points.
